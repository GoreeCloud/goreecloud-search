# GoreeCloud Search — Benefits

The implemented foundation is designed to support these benefits without claiming capabilities that do not yet exist:

- Privacy-aware source selection before provider execution.
- Self-hostable and first-party-friendly architecture.
- Replaceable provider adapters rather than provider lock-in.
- GoreeCloud Index as the long-term native first-party path.
- Explicit source modes instead of silent fallback to unrelated engines.
- Transparent, testable query interpretation and deterministic planning.
- A path toward provenance, Lenses, Private View, user-controlled ranking, and source-backed answers.
