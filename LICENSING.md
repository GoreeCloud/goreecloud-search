# GoreeCloud Search Licensing Decision

**Project license:** GNU Affero General Public License v3.0 or later (`AGPL-3.0-or-later`)

**Decision date:** 2026-09-16

## Rationale

GoreeCloud Search is designed as a self-hostable, network-interactive search service. Strong reciprocal licensing for modified hosted versions aligns with GoreeCloud's open-source, self-hosting, inspectability, and user-control objectives.

AGPL-3.0-or-later is therefore the selected project-specific license for GoreeCloud Search. This is consistent with the GoreeCloud-wide default while remaining an explicit product-level decision rather than an automatic inheritance.

## Scope

This decision applies to GoreeCloud-owned code in this repository unless a file or component clearly carries a different compatible license or third-party notice.

Third-party and upstream material remains governed by its own applicable licenses. GoreeCloud must not relicense third-party code beyond the rights granted by its copyright holders.

## Repository requirements

- Root license/rights notice identifies `AGPL-3.0-or-later`.
- Project metadata and primary documentation identify the same SPDX expression.
- Distributed releases must include the applicable GNU AGPL v3 license text and required notices.
- Any future license change requires a controlled compatibility and contributor-rights review.
